# IVA DECK

[English](../README.md)

**Tastatură macro construită de Ioan-Andrei Ivașcu**, cu PCB propriu, ESP32, nouă taste mecanice, trei potențiometre, display și aplicație Python / PyQt6.

Proiectul academic original a fost prezentat în iunie 2025 la Facultatea de Matematică și Informatică, Universitatea din București, cu titlul „Tastatură Inteligentă cu Recunoaștere Comportamentală asistată de AI”.

[![Demonstrație IVA DECK](media/demo-preview.gif)](media/iva-deck-demo.mp4)

[Filmarea completă cu sunet — 2 minute și 8 secunde](media/iva-deck-demo.mp4)

Include macro-uri configurabile, control de volum Windows, display ST7789, card microSD, proximitate, buzzer și comunicare JSON prin USB / Bluetooth serial. Componenta AI folosește Random Forest pentru un experiment de recunoaștere comportamentală. Transmisia audio completă și comenzile vocale nu sunt finalizate.
